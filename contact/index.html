Help improve QTimer

The public QTimer repository is the clearest place to report a problem or start a conversation.

Open a GitHub Issue

Use the verified public QTimer repository’s Issues page ↗ for all four contact paths:

  • Report a bug.
  • Suggest a feature.
  • Ask a privacy question.
  • Report inappropriate or unsafe AI output.

For a private question, email nemo20k.dev@gmail.com. There is no contact form; please keep public issue reports focused and remove sensitive details before posting.

Useful bug-report details

For a bug, include your browser and version, device and operating system, expected behavior, actual behavior and steps to reproduce it. Remove sensitive content and sanitize workout URLs before posting publicly.

Keep private information out of issues

Do not post private health information, complete AI prompts containing sensitive information, confidential timer links, authentication details or secrets. If a URL contains a workout title or labels you do not want public, remove or replace those parameters before sharing it.

Unsafe AI output

If QTimer returns inappropriate or unsafe content, report it through the Issues page without posting the original prompt when it contains sensitive information. A short description of the problem and a sanitized example is enough.
